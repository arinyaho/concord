# Initiative Deep Gate Evidence

## Problem

`initiative-to-prs` requires Deep capability for material architecture and behavioral decisions, but its current exception lets the active agent perform the pass when it considers its own resolved model Deep. A General orchestrator can therefore record a role label such as `active root agent` and advance without a separately observable Deep review.

## Decision

When Stage 1 identifies a Deep decision, require a separate Deep-capability specialist in clean context. The active orchestrator never satisfies this gate itself, regardless of model, reasoning effort, or self-assessment.

Before checkpoint 1, the Stage 1 handoff must identify the decision, specialist invocation or agent, requested and resolved model, provider/catalog basis, reasoning effort when exposed, completed conclusion, and unresolved assumptions. Critical cryptography, security, and migration decisions retain the existing requirement for a second independent Deep reviewer with separate evidence.

Checkpoint 1 and Stage 2 remain blocked when the handoff is missing or unreadable, a model identity is unresolved, the specialist did not complete successfully, the evidence does not cover the proposed decision, or required independent-review evidence is absent. User approval cannot replace missing technical evidence.

The general permission to avoid unnecessary delegation is subordinate to this gate.

## Trade-off

Even a Deep active agent pays for a separate specialist call. The cost buys an observable boundary and removes ambiguous self-certification from a workflow whose orchestrator is normally General.

## Residual exposure

This package currently has no initiative executor, harness-owned model receipt, pre-tool hook, or tracker-mutation wrapper. The change therefore strengthens the skill contract and its packaged tests but cannot make checkpoint or external mutation blocking unbypassable at runtime. A hard guarantee requires a harness-owned receipt plus a mandatory transition or mutation interception point; this change does not pretend a Markdown or agent-authored JSON validator can establish model capability.

## Verification

- The initiative routing contract requires a separate Deep specialist and rejects the active agent as satisfying the gate.
- Stage 1 requires readable, decision-specific completion evidence before checkpoint 1 or Stage 2 mutation.
- Claude, Codex, and Copilot packaged copies retain the rule after bundling.
- The initiative skill test fails on the prior contract and passes after the change.
